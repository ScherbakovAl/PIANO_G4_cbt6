===============================
IBIS files for STM32G4 devices:
===============================

The package contains :

   + IBIS Files for STM32G431_441 devices on different packages :

	  o LQFP100
	  o LQFP80
	  o LQFP64
	  o LQFP48
	  o LQFP32
	  o UFBGA64
	  o UFQFPN48
	  o UFQFPN32
	  o WLCSP49

   + IBIS Files for STM32G471_473_474_483_484 devices on different packages :

          o LQFP128
	  o LQFP100
	  o LQFP80
	  o LQFP64
	  o LQFP48
	  o TFBGA100
	  o UFQFPN48
	  o WLCSP81
	  
   + IBIS Files for STM32G491_4A1 devices on different packages :

	  o LQFP100
	  o LQFP80
	  o LQFP64
	  o LQFP48
	  o UFBGA64
	  o UFQFPN48
	  o UFQFPN32
	  o WLCSP64
