# Новые функции для работы с Flash памятью в формате uint32_t

## Обзор

Добавлены две новые функции для чтения и записи данных в Flash память STM32G474CBT6 в формате `uint32_t`, которые безопасны для вызова из прерываний.

## Функции

### 1. `Read_uint32()`

```cpp
void Read_uint32(uint32_t Address, volatile uint32_t* pData, uint32_t Size);
```

**Описание:** Чтение данных из Flash памяти в формате uint32_t

**Параметры:**
- `Address` - Адрес начала чтения во Flash (должен быть выровнен по 4 байта)
- `pData` - Указатель на массив uint32_t для сохранения прочитанных данных
- `Size` - Размер данных в **БАЙТАХ** (не в элементах uint32_t!)

**Особенности:**
- ✅ Безопасна для вызова из прерывания (использует критические секции)
- ✅ Размер Size автоматически округляется вверх до кратного 4
- ✅ Быстрее чтения побайтно (чтение 32-битными словами)

**Пример использования:**
```cpp
__attribute__((aligned(32))) volatile uint32_t bin_data_32[512];
Read_uint32(0x08008000, bin_data_32, 2048); // Прочитать 2048 байт (512 uint32_t)
```

---

### 2. `Flash_uint32()`

```cpp
void Flash_uint32(uint32_t Address, volatile uint32_t* Data, uint32_t size);
```

**Описание:** Запись данных в Flash память в формате uint32_t

**Параметры:**
- `Address` - Адрес начала записи во Flash (должен быть выровнен по 8 байт!)
- `Data` - Указатель на массив uint32_t с данными для записи
- `size` - Размер данных в **БАЙТАХ** (не в элементах uint32_t!)

**Особенности:**
- ✅ Безопасна для вызова из прерывания (использует критические секции)
- ✅ Размер size автоматически округляется вверх до кратного 8 (запись doubleword)
- ⚠️ **Важно:** Перед записью необходимо стереть страницу Flash с помощью `Erase()`

**Пример использования:**
```cpp
__attribute__((aligned(32))) volatile uint32_t bin_data_32[512] = {данные};
uint32_t addr = 0x08008000;

// 1. Стираем страницу
FlashPageInfo_t info = GetPageAndBank(addr, 2048);
Erase(info.start_page, info.bank);

// 2. Ждём завершения стирания
__DSB();
__ISB();

// 3. Записываем данные
Flash_uint32(addr, bin_data_32, 2048); // Записать 2048 байт (512 uint32_t)
```

## Изменения в переменных

### До:
```cpp
uint8_t bin_data[2048] = {};
__attribute__((aligned(32))) volatile uint32_t bin_data_32[256] = {};
```

### После:
```cpp
__attribute__((aligned(8))) uint8_t bin_data[2048] = {};
__attribute__((aligned(32))) volatile uint32_t bin_data_32[512] = {}; // 512 uint32_t = 2048 байт
```

**Изменения:**
1. ✅ `bin_data` теперь выровнен по 8 байтам (было без выравнивания)
2. ✅ `bin_data_32` увеличен с 256 до 512 элементов (теперь соответствует размеру bin_data)
3. ✅ Оба массива теперь одинакового размера в байтах: 2048 байт

## Примеры использования

### Пример 1: Конвертация uint8_t → uint32_t и запись в Flash

```cpp
// Конвертируем bin_data[2048] -> bin_data_32[512]
for (uint32_t i = 0; i < bin_data_length / 4; i++) {
    bin_data_32[i] = bytes_to_uint32_shift(&bin_data[i * 4]);
}

// Записываем в flash
const uint32_t addr = 0x08008000;
FlashPageInfo_t info = GetPageAndBank(addr, bin_data_32_length);
Erase(info.start_page, info.bank);
__DSB();
__ISB();
Flash_uint32(addr, bin_data_32, bin_data_32_length);
```

### Пример 2: Чтение из Flash и конвертация uint32_t → uint8_t

```cpp
// Читаем из flash в uint32_t массив
Read_uint32(0x08008000, bin_data_32, bin_data_32_length);

// Конвертируем uint32_t обратно в uint8_t
for (uint32_t i = 0; i < bin_data_32_length / 4; i++) {
    uint32_to_bytes_shift(bin_data_32[i], &bin_data[i * 4]);
}
```

### Пример 3: Использование из прерывания

```cpp
void USART2_IRQ() {
    if (LL_USART_IsActiveFlag_RXNE_RXFNE(USART2)) {
        // Безопасно вызывать из прерывания!
        Read_uint32(0x08008000, bin_data_32, 2048);
        
        // Запись (убедитесь что страница предварительно стерта!)
        // Flash_uint32(0x08008000, bin_data_32, 2048);
    }
}
```

### Пример 4: Прямая работа только с uint32_t

```cpp
// Заполняем данными
for (uint32_t i = 0; i < 512; i++) {
    bin_data_32[i] = 0x12345678 + i;
}

// Записываем
FlashPageInfo_t info = GetPageAndBank(0x08008000, 2048);
Erase(info.start_page, info.bank);
__DSB();
__ISB();
Flash_uint32(0x08008000, bin_data_32, 2048);

// Проверяем
__attribute__((aligned(32))) volatile uint32_t verify_data[512] = {};
Read_uint32(0x08008000, verify_data, 2048);

for (uint32_t i = 0; i < 512; i++) {
    if (bin_data_32[i] != verify_data[i]) {
        // Ошибка!
    }
}
```

## Функции конвертации uint8_t ↔ uint32_t

В коде доступны следующие функции для конвертации (уже существовали):

- `bytes_to_uint32_shift()` - конвертация 4 байта → uint32_t (побитовые сдвиги)
- `uint32_to_bytes_shift()` - конвертация uint32_t → 4 байта (побитовые сдвиги)
- `bytes_to_uint32_pointer()` - быстрая конвертация (требует выравнивание)
- `bytes_to_uint32_safe()` - через memcpy (переносимый вариант)

**Рекомендация:** Используйте `*_shift()` варианты для универсальности!

---

## ⚠️ Важные замечания

1. **Выравнивание адресов:**
   - Для `Read_uint32()` адрес должен быть кратен **4 байтам**
   - Для `Flash_uint32()` адрес должен быть кратен **8 байтам**

2. **Размер параметра Size/size:**
   - Всегда указывается в **БАЙТАХ**, не в количестве элементов uint32_t
   - Например: 2048 байт = 512 элементов uint32_t

3. **Стирание перед записью:**
   - Всегда необходимо стирать страницу Flash перед записью
   - Используйте барьеры `__DSB()` и `__ISB()` после стирания

4. **Безопасность в прерываниях:**
   - Обе функции используют критические секции (`__disable_irq()`/`__enable_irq()`)
   - Безопасны для вызова из любого прерывания
   - Но учитывайте время выполнения операций Flash!

## Производительность

- **Чтение:** `Read_uint32()` быстрее чем `Read()` т.к. читает 32-битными словами
- **Запись:** `Flash_uint32()` аналогична по скорости `Flash()`, но удобнее для uint32_t
- **Критические секции:** Минимальное влияние на производительность
